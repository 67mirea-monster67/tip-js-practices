# Практическая работа № 9

HTTP API на Express

`npm ci`, затем `npm start`. API доступен на http://127.0.0.1:5505/api.

`npm run kr3 -- 5515` включает режим контрольной. `GET /api/tasks?completed=true` возвращает массив выполненных задач, а `POST /api/tasks` проверяет тело запроса. Данные хранятся в памяти сервера.

`npm test` запускает модульные и HTTP-проверки.
