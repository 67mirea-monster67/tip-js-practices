# Практическая работа № 7

Компонентный интерфейс на React

`npm ci`, затем `npm run dev`. Откройте http://127.0.0.1:5173/.

Приложение поддерживает создание, изменение, удаление и переключение статуса задач. Фильтрация выполняется на клиенте, состояние хранится в памяти страницы.

`npm test` проверяет валидацию, фильтры, статистику и операции над задачами. `npm run build` собирает приложение.
