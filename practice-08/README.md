# Практическая работа № 8

React и учебный API

`npm ci`. В первом терминале запустите `npm run api`, во втором — `npm run dev`. Откройте http://127.0.0.1:5173/.

Хук `useTaskData` управляет загрузкой, ошибками и изменениями задач. Добавьте `?trace` к адресу страницы и откройте консоль браузера, чтобы увидеть `isLoading` и число задач.

`npm test` запускает проверки API, интеграции и React. `npm run build` собирает клиент.
